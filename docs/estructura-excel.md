# Estructura usada del Excel

La app lee la hoja `Pool` de cada participante.

| Bloque | Filas | Uso |
|---|---:|---|
| Nombre | C5 | Nombre del participante |
| Partidos de grupo | C6:C77 | Predicción `signo|golesLocal-golesVisitante` |
| Posiciones de grupo | C80:C127 | 1º a 4º de cada grupo A-L |
| Clasificados a dieciseisavos | C130:C161 | Equipos clasificados |
| Partidos de dieciseisavos | C164:C179 | Marcador exacto |
| Clasificados a octavos | C182:C197 | Equipos clasificados |
| Partidos de octavos | C200:C207 | Marcador exacto |
| Clasificados a cuartos | C210:C217 | Equipos clasificados |
| Partidos de cuartos | C220:C223 | Marcador exacto |
| Clasificados a semifinales | C226:C229 | Equipos clasificados |
| Partidos de semifinales | C232:C233 | Marcador exacto |
| Clasificados a 3º/4º | C236:C237 | Equipos, 0 puntos según reglas |
| Finalistas | C240:C241 | Equipos finalistas |
| 3º/4º puesto | C244 | Marcador, 0 puntos según reglas |
| Final | C247 | Marcador exacto |
| Cuadro de honor | C250:C252 | Campeón, subcampeón, tercero |
| Premios individuales | C253:C258 | Bota/Balón Oro, Plata y Bronce |
